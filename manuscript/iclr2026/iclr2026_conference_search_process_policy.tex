\section{Search Process Policy}
\label{sec:policy}

% Paragraph purpose: Define the task, episode, observation, and operation contract compactly.
An episode fixes $(x, A, m, B)$: a task $x = (D, s_0, G)$ with deterministic grounded domain $D$, a declared algorithm $A$ given as input, a modality adapter $m$, and a frozen budget $B$. At step $t$ the policy sees $o_t = \phi_m(c_t)$, a text-state, visual-state, or multimodal-state rendering of the decision context that must be decision-sufficient (exposing every fact the exact teacher uses at $t$), with Search Memory and candidates kept textual.

% Paragraph purpose: Define Typed Search Operation, Search Memory, Algorithm Invariant, and Trusted Search Runtime with the ownership rule.
\textbf{Typed Search Operation.} The policy emits $u_t = (\tau_t, \theta_t)$, a type from $A$'s vocabulary plus every exploration-determining operand, and an emission that omits one is invalid. \textbf{Search Memory.} $M_t$ is bounded runtime-held state (frontier, visited table, BFWS novelty counters), not model state, and $o_t$ is the policy's only channel to history.
% TODO: the fixed Search Memory capacity value is an open pre-registration
% prerequisite (writing_design_tree.md); pin the value here once frozen.
\textbf{Algorithm Invariant.} Deterministic per-algorithm properties are checked on every operation, namely FIFO order (BFS), novelty and goal-count priority (BFWS \citep{lipovetzky2017bestfirst}), and $g + 3h_{\rm add}$ or $h_{\rm add}$ order under a declared tie-break (weighted A* \citep{hart1968formal,pohl1970heuristic} and greedy best-first over $h_{\rm add}$ \citep{bonet2001planning}), and compliance establishes neither termination, completeness, optimality, nor success.
% TODO: the per-algorithm tie-breaking convention must be recorded in the
% Appendix evidence contract; the exact rule is not pinned in current sources.
\textbf{Trusted Search Runtime.} The runtime only validates, applies, persists, or rejects, never choosing omitted operands, reordering candidates, or repairing, so raw emissions replay to the same trace (schemas and invariants in Appendix~\ref{appendix}).

% Paragraph purpose: Define the learning objective, process supervision on trusted Search-Trace Segments, with optional DAgger.
Process supervision is token-level cross-entropy cloning of the teacher's operation on Search-Trace Segments, bounded slices of replay-verified exact traces collected in a dataset $\train$, which optional DAgger \citep{ross2011dagger} extends with teacher corrections on visited contexts.
