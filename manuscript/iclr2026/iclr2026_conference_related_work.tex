\textbf{Learning to plan from plans.} Language models trained for classical planning output plans, either from scratch~\citep{rossetti2024learning} or by fine-tuning pretrained ones on planner-generated plans~\citep{pallagani2022plansformer,bohnet2024exploring,li2024unlocking,belcamino2026generalization}, sometimes reasoning along a candidate plan~\citep{verma2025teaching,emami2026close}. \citet{belcamino2026generalization} report sensitivity to surface representations: symbol anonymization causes significant drops despite preserving plan semantics. We supervise the search instead, including states that never reach the plan.

\textbf{Learning from search traces.} Models have also learned from BFS, A*, and other search traces in mazes, Sokoban, Countdown, code repair, and deductive proofs~\citep{yang2022chain,lehnert2024beyond,su2024dualformer,gandhi2024stream,moon2024learning,opedal2026learning}. Searchformer beats plan-only training with a tenth of the data~\citep{lehnert2024beyond}, and the closest work, \mbox{System-1.x}, fine-tunes a pretrained LLM on A* traces in mazes and Blocksworld and shows that it also works with BFS or DFS traces in mazes~\citep{saha2024system1x}. Three questions remain open across these studies. They cover a few puzzle or reasoning tasks and do not compare what different algorithms cost to learn; none learns width-based search, a mainstay of classical planning; and each evaluates the learned search only within the task it was trained on. We compare four algorithms, including BFWS, across 12 PDDL domains, and test transfer to logic, math, and code.

% Paragraph purpose: Credit VLM planning, then defend novelty: none of these models is trained to execute a search, and none tests which input channel a trained model relies on; our corruption study answers that (F2), echoing language-prior findings. Supports Introduction ¶2 (VLM question) and ¶5.
\textbf{Planning from images.} VLMs have been evaluated as planners and as grounders for a symbolic planner~\citep{merler2025viplan}, fine-tuned to simulate action outcomes from images for a PDDL planner~\citep{hao2025simulation}, and trained to plan through image sequences, outperforming text reasoning on visual navigation tasks~\citep{xu2025visual}. None of these models is trained to execute a search, and none tests which input channel a trained model relies on when the same task arrives as text, images, or both. We train a VLM to execute the search and corrupt each channel in turn: the learned search relies on the text (Section~\ref{sec:results-modality}), echoing findings on language priors~\citep{zhu2020overcoming}.
