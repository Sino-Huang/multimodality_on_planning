# Cross-harness knowledge policy

This directory is a compatibility/tool-state surface for harnesses that require
`.omo/knowledges/*.md`. It stays in place; do not move `.omo/`.

The current authority is GitHub issue #38 (`Spec: Teach VLMs executable search processes across
modalities`) and its ready-for-agent tickets #39-#108, with `CONTEXT.md` as the #38-first
glossary. Canonical planning state lives in `docs/high_level_plans/research_execution_plan.md`,
`task_plan.md`, `notes.md`, and the active task's `.claude/evidence/` verification summary,
subject to `docs/partial_obsolescence_exceptions.md`.

The CGAS closeout retained here is a historical record (retained evidence/infrastructure), not an
active milestone and not a current #38 result. Completed `.omo` notes are archived in
`.claude/archive/context-hot-snapshot-2026-08-10.tar.gz` and tracked versions remain recoverable
through Git history.

Combined `.claude/knowledge/` and `.omo/knowledges/` content must stay below 25 KB and six
Markdown files. Do not create per-session, per-agent, per-test, or per-review notes.
