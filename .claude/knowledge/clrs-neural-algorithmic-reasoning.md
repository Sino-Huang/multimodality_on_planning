# Neural algorithmic reasoning literature (2026-07-28)

- Veličković et al., “The CLRS Algorithmic Reasoning Benchmark” (ICML 2022), arXiv:2205.15659. Procedurally generated traces for 30 algorithms; supervision includes input/output and intermediate hints (locations, categorical, masks); evaluates extrapolation to larger graphs and algorithm transfer. https://arxiv.org/abs/2205.15659
- Markeeva et al., “The CLRS-Text Algorithmic Reasoning Language Benchmark” (2024), arXiv:2406.04229. Text serialization of CLRS traces; 30 tasks; fine-tunes LMs; tests length/input-distribution OOD. https://arxiv.org/abs/2406.04229
- Ibarz et al., “A Generalist Neural Algorithmic Learner” (2022), arXiv:2210.02174. Transformer/GNN-style processor trained with execution traces and hint supervision across algorithms; evaluates size/generalization. https://arxiv.org/abs/2210.02174
- Rodionov & Prokhorenkova, “Neural Algorithmic Reasoning Without Intermediate Supervision” (NeurIPS 2023), arXiv:2306.13411. Input-output-only plus self-supervised latent regularization; competitive with trajectory-supervised CLRS, including sorting and graph tasks. https://arxiv.org/abs/2306.13411
- Minder et al., “SALSA-CLRS” (LoG 2023), arXiv:2309.12253. Sparse/scalable CLRS extension; distributed/randomized algorithms; addresses dense fully connected execution model bottleneck. https://arxiv.org/abs/2309.12253
- Georgiev et al., “Neural Algorithmic Reasoning for Combinatorial Optimisation” (2023), arXiv:2306.06064. Pre-trains on algorithms before combinatorial optimization; demonstrates algorithmic pretraining benefit. https://arxiv.org/abs/2306.06064
- Kujawa et al., “Neural Algorithmic Reasoning with Multiple Correct Solutions” (2024), arXiv:2409.06953. Bellman-Ford and DFS; samples/validates multiple valid trajectories rather than one canonical solution. https://arxiv.org/abs/2409.06953
- Huang et al., “Neural Algorithmic Reasoning for Hypergraphs with Looped Transformers” (2025), arXiv:2501.10688. Looped Transformer simulates Dijkstra and Helly on hypergraphs with degradation/encoding; theoretical guarantees. https://arxiv.org/abs/2501.10688
- Veličković et al., “Neural Execution of Graph Algorithms” (ICLR 2020), arXiv:1910.10593. Pointer Graph Networks learn algorithm execution using intermediate node/edge traces; evaluates BFS, DFS, Bellman-Ford and OOD graph sizes. https://arxiv.org/abs/1910.10593
- Laskin et al., “In-Context Reinforcement Learning via Algorithm Distillation” (2022), arXiv:2210.14215. Transformer trained on histories generated by RL algorithms; predicts next actions from execution history, emphasizing in-context policy improvement; not CLRS and no explicit graph traces. https://arxiv.org/abs/2210.14215
