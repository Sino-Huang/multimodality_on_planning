# CGAS Characterization Final Bundle

- The only final publication profile is `regular_bundle_linkat_v1`, bound under `policies.final_publication_profile` in the run-contract fingerprint.
- `cgas-final-bundle-v1` is a strict regular-file format: fixed magic, four-byte big-endian canonical-header length, canonical JSON metadata, then the three raw logical members in `run-contract.json`, `characterization.jsonl`, `characterization_manifest.json` order.
- Final consumers use `verify_characterization(... final_root=<bundle file>)`; verification is read-only, rejects unsafe file metadata, parses without extraction, and invokes the same authoritative final-member science checks as private candidates.
- Publication creates an anonymous mode-0600 `O_TMPFILE` inode in an external owner-mode-0700 private root on the destination filesystem. It writes and fsyncs the bundle, pins inode/mode/owner/link-count/size by descriptor, and performs authoritative scientific verification from bytes read from that descriptor. No private bundle pathname exists.
- Repo-local GPFS returns `ENOENT` for `linkat(..., AT_EMPTY_PATH)`. The selected profile therefore publishes the held anonymous inode with `linkat(AT_FDCWD, /proc/self/fd/<fd>, trusted_tmp_dirfd, final_name, AT_SYMLINK_FOLLOW)`. The destination device/inode/link count must match the source descriptor before the trusted destination directory is fsynced.
- There is no private source unlink or private-parent fsync in this anonymous-inode transaction. After linking, destination fsync and read-only destination bundle verification are mandatory. Any failure after the final name becomes visible is durability-indeterminate; the visible winner is never removed or adopted.
- Bundle headers translate invalid UTF-8 and JSON framing errors into `BundleError`. Checkpoint and final verifier leaves enforce pre-read byte caps; a sparse one-terabyte checkpoint is rejected before `pread`.
- The source has no private filesystem name. Same-UID processes can inspect `/proc/self/fd` only subject to OS `/proc` permissions; that procfs visibility is the explicit remaining threat boundary, while the publication source remains descriptor-pinned rather than caller-named.
- Final destinations are exactly one component directly below the descriptor-opened owner-mode-0700 `<repository>/tmp/.cgas-characterization` child. The shared `tmp` parent is only used to create/open the child after current-owner/no-group-or-other-write validation.
- Bundle SHA-256 is a contract-scoped provenance identity: equal run-contract bytes and fingerprints require equal bundle bytes across operational histories. It is not a cross-shard scientific-determinism oracle, because changing `shard_count` deliberately changes the contract, embedded member, header fingerprint, and bundle SHA-256. Compare exact JSONL and manifest bytes, including artifact/source/count/implementation digests, across such contracts.
