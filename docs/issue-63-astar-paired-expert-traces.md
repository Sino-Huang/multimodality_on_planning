# Retired issue 63 optimal-A* trace design

This design was retired after the issue-62 optimal-A* qualification produced a
governed `VALID_STOP`: optimal search required hundreds of thousands of
expansions and the original exact event schema projected to multi-gigabyte
traces. The retained v1 code, manifests, and attempt evidence remain available
for provenance; they must not be rerun as the active issue-63 design.

The active replacement, its compact trace contract, and operator commands are
documented in [issue-63-best-first-expert-traces.md](issue-63-best-first-expert-traces.md).
