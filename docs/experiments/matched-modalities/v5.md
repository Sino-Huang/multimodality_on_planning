# Unlabelled 128px matched study

The user requested 128×128 state PNGs without annotation to reduce storage.
Study v5 renders initial and current states directly from retained VFG stages
at 128px with all text labels disabled, including source showName/showlabel
flags. No labels, fact panels, titles or leader lines are added to state PNGs.
Static context and source-goal pages remain separate and complete. The initial
scene, current scene and context/goal pages accompany each image-modality call.

Selected tasks, source records, targets, splits, order, Search Memory, model
revision and training settings remain unchanged. The four verified v3 text
adapters are retained; visual and multimodal adapters must train on v5 inputs.
The unchanged corpus includes 2,156 selected records and 1,588 scene states,
including the full 152-state held-out closure. Previous assets remain intact.

The user-approved 12-hour allocation is carried forward: 4,500 seconds of
qualification, 17,100 training/development and 21,600 evaluation. Every previous
attempt counts in the original v2 ledger. V4 hardware evidence is historical;
v5 requires fresh image-modality qualification because its inputs changed.
Processor resizing is measured rather than equating PNG dimensions with model
image tokens. Preparation, GPU qualification and training report progress.

This condition deliberately removes object-name text from state images. It
measures unlabelled low-resolution scene input within the shared planning
interface; separate static/goal pages and shared candidate information still
contain text. It is not the earlier readable annotated-state condition.

Execution evidence will be recorded after complete preparation and qualification.
