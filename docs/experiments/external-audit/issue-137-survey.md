Purpose: pick 1-2 published evaluations on which to run our control-only identity audit
(`random_valid` vs `reference`, no model runs). All facts below were read from the primary
sources (paper PDF/HTML on arXiv or the venue proceedings, and the official repository);

## Selection by the fixed rule

1. Drop `CPU feasible? = no`: WebShop, RAP, LLM-First Search, EmbodiedBench. Remaining:
   AutoPlanBench, ScienceWorld, GLAM.
2. No remaining candidate predicts identical or saturated (all three are type B and predict
   divergent), so criterion 2 does not separate them.
3. Most cited: ScienceWorld (320) > GLAM (287) > AutoPlanBench (26).

**Selected: ScienceWorld** (type B, prediction divergent, code
https://github.com/allenai/ScienceWorld @ e8216d6044e8e39be9fcb185e3b2dfb602584b52).
The second-ranked candidate (GLAM) has the same prediction (divergent), so only one benchmark
is audited.

**No candidate predicts identical/saturated: yes, among CPU-feasible candidates.** The
only saturated prediction (LLM-First Search) comes from a token-denominated budget that does
not bind a control, and that candidate is dropped at the feasibility step. The only
type-A-like published interface found (LFG: the LLM scores every frontier and the planner
takes the argmax) releases no evaluation harness; even so, its frontiers are ordered *by the
model's scores*, not by a fixed structure that ignores them, so it would not be predicted
identical either. None of the published interfaces we found has our complete-set submission
contract, in which the heap order does not depend on the order of submission.
