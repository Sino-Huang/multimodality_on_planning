Search Process Policy Realignment

Status: openMethod briefVersion 0.3Updated 2026-08-21

Proposed: train an algorithm-conditioned Search Process Policy on canonical planner traces, then test observable, algorithm-valid search decisions across matched modalities. No trained policy or model-efficacy result exists.

Truth labels state maturity; evidence labels state support. The embedded schema is this brief's factual source.

One-minute brief

Challenge. Prior text-LLM evidence separates local operational reasoning from structural enumeration. The proposed study tests a training target for observable search decisions, rather than local replayed-transition imitation.

Execution boundary. Under the proposed protocol, the model emits typed operations; a trusted runtime validates them, applies trusted transitions, and returns the canonical next observation. It cannot select, rank, repair, or replace a model decision. The full runtime API is not implemented.

Rendering boundary. Retained CGAS production rendering uses a locally generated LAMA-first supplied plan; Planimation only interprets that plan and renders VFG/PNG, never a hosted solver. A proposed per-state/search rendering contract must retain this no-hosted boundary and needs approval if it changes ADR-0001 plan sourcing. Proposed BFS/IW/A* traces are not implied to be LAMA plans.

Implemented now

Authoritative PDDL state/frame provenance and BFS/IW trace/verifier infrastructure exist; no model result follows.

Available only under proposal

Matched modality state+goal, a fixed typed search-memory API/capacity, and student-visited DAgger corrections.

Input / output

Canonical traces, modality-specific state+goal, and typed memory enter the protocol; the model emits a typed operation, with a complete episode/evidence record retained.

Success

Planned full-episode, budgeted, algorithm-valid search outcomes. Observed result: TBD.

Limitations and supervisor decisions

No model efficacy result exists. All experiments, corpus construction, runtime API, trained policies, and evaluations described here are designed or planned. Existing rendering and provenance evidence does not prove predicate recoverability, modality parity, training, or search efficacy.
