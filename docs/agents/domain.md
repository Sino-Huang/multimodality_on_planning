# Domain Docs

Before exploring, read `CONTEXT.md` and relevant ADRs under `docs/adr/` when they exist. Missing domain documentation is not an error; proceed without suggesting it be created upfront.

This repository uses a single-context layout:

```
/
├── CONTEXT.md
├── docs/adr/
└── src/
```

Use terminology defined in `CONTEXT.md`. Explicitly flag proposals that contradict an existing ADR.
